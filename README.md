#Primitive DB

Учебная консольная база данных на Python с хранением метаданных
и записей таблиц в JSON-файлах.

Приложение позволяет создавать и удалять таблицы, добавлять,
просматривать, обновлять и удалять записи через текстовые команды.

Поддерживаются типы данных int, str и bool. Столбец ID создаётся
автоматически. Перед удалением записей и таблиц программа
запрашивает подтверждение.


## Требования

- Python 3.12 или новее.
- uv.
- make — для выполнения команд Makefile.

Основные зависимости приложения:

- prettytable — табличный вывод записей.
- prompt — ввод команд пользователя.

Для проверки кода используется Ruff из группы зависимостей dev.

## Команды


### Управление таблицами

- `create_table <имя> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать таблицы.
- `drop_table <имя>` — удалить таблицу после подтверждения.
- `info <имя>` — показать столбцы и количество записей.


### Работа с записями

- `insert into <таблица> values (...)` — добавить запись.
- `select from <таблица>` — показать все записи.
- `select from <таблица> where <столбец> = <значение>` — выбрать записи.
- `update <таблица> set <столбец> = <значение> where <условие>` —
  обновить записи.
- `delete from <таблица> where <условие>` — удалить записи
  после подтверждения.


### Формат значений

- Строки записываются в двойных кавычках: "Anna".
- Целые числа записываются без кавычек: 25, -10, +28.
- Логические значения: true и false.
- Поддерживаются условия равенства вида: age = 25.
- Для подтверждения удаления введите латинскую y.
  Любой другой ответ отменяет операцию.


## Пример работы

Запустите приложение:

```bash
make run
```

Затем последовательно введите команды:

```text
create_table users name:str age:int is_active:bool
insert into users values ("Anna", 25, true)
select from users
select from users where age = 25
update users set age = 26 where ID = 1
select from users where ID = 1
info users
delete from users where ID = 1
```

Подтвердите удаление записи, введя латинскую y.

После этого выполните:

```text
drop_table users
```

Подтвердите удаление таблицы, введя латинскую y.

Завершите работу:

```text
exit
```

Пример предполагает, что таблица users ещё не существует.


## Хранение данных

Метаданные таблиц сохраняются в файле db_meta.json.
Записи каждой таблицы хранятся в отдельном JSON-файле
в каталоге data/.

Пути к данным определяются относительно текущей рабочей директории.
Для предсказуемого расположения файлов запускайте приложение
из корня проекта.

Файл db_meta.json и каталог data/ добавлены в .gitignore
и не включаются в репозиторий.


## CRUD-операции

Перед работой с записями создайте таблицу:

```text
create_table users name:str age:int is_active:bool
```

### Добавление записи

```text
insert into users values ("Sergei", 28, true)
```

Значения указываются в порядке столбцов при создании таблицы.
Все пользовательские поля обязательны.

Значение ID передавать не нужно: оно генерируется автоматически
как максимальный ID среди текущих записей плюс один.
Для пустой таблицы первый ID равен 1.

### Чтение записей

Все записи:

```text
select from users
```

Записи по условию:

```text
select from users where age = 28
```

Результат выводится в виде таблицы с помощью PrettyTable.

### Обновление записей

```text
update users set age = 29 where name = "Sergei"
```

Можно обновить несколько полей:

```text
update users set age = 30, is_active = false where name = "Sergei"
```

Обновляются все записи, соответствующие условию.
Изменять ID нельзя.

### Удаление записей

```text
delete from users where ID = 1
```

Удаляются все записи, соответствующие условию.

### Информация о таблице

```text
info users
```

Команда показывает имя таблицы, столбцы с типами и количество записей.

### Правила ввода

- Строки вводятся в двойных кавычках: `"Sergei"`, `"Иван Петров"`.
- Целые числа вводятся без кавычек: `28`, `-5`.
- Логические значения вводятся без кавычек: `true`, `false`.
- Тип значения должен соответствовать типу столбца.
- В `where` поддерживается одно условие равенства.
- Для `update` и `delete` условие `where` обязательно.
- Команда `select` без `where` возвращает все записи.

### Хранение записей

Записи таблицы `users` сохраняются в файле `data/users.json`.

После успешного добавления, обновления или удаления записей изменения
сохраняются в файл. При запуске из той же рабочей директории
ранее сохранённые данные доступны снова.

При создании таблицы создаётся пустой файл данных.
При удалении таблицы удаляются её метаданные и файл данных.

Файл `db_meta.json` и директория `data/` исключены из Git
через `.gitignore`.


## Декораторы и замыкания

Повторяющаяся логика вынесена в модуль
`src/primitive_db/decorators.py`.

### Обработка ошибок

Декоратор `handle_db_errors` обрабатывает ошибки валидации,
отсутствующие ключи, отсутствие файлов и другие ошибки
работы с файловой системой.

При обработанной ошибке выводится сообщение, а операция возвращает
`None`. Обработчик команды не сохраняет такой результат вместо данных.

Пример некорректного ввода для столбца `age:int`:

```text
insert into users values ("Sergei", "wrong", true)
```

Программа сообщает об ошибке типа и продолжает принимать команды.

### Подтверждение удаления

Декоратор `confirm_action(action_name)` запрашивает подтверждение
перед удалением таблицы или записей:

```text
Вы уверены, что хотите выполнить "удаление записей"? [y/n]:
```

Для выполнения операции нужно ответить `y`.
Регистр и пробелы по краям ответа не учитываются.
Другой ответ отменяет операцию без изменения данных.

### Замер времени

Декоратор `log_time` применяется к `insert` и `select`.
Время измеряется с помощью `time.monotonic()` и выводится
с точностью до трёх знаков после запятой:

```text
Функция select выполнилась за 0.000 секунд.
```

Для небольших операций значение может округляться до `0.000`.

Замер `insert` включает загрузку записей, но не последующее сохранение
в обработчике команды. Замер `select` включает работу с кэшем
и выборку, но не предварительную загрузку файла.

### Кэширование выборок

Функция `create_cacher()` создаёт кэш в замыкании.
Повторный вызов с тем же ключом возвращает сохранённый результат
без повторного вызова функции получения данных.

В `select` ключ зависит от текущего содержимого таблицы
и условия выборки. После изменения записей используется другой ключ,
поэтому старый результат не подменяет актуальные данные.

Кэш хранит до 128 результатов. При заполнении удаляется
самый давно добавленный результат. Кэш существует только
до завершения программы.

Результаты выборки возвращаются в виде копий записей.
Кэширование не отменяет загрузку JSON-файла и не гарантирует
ускорение на небольших таблицах.

## Структура проекта

```text
src/primitive_db/
├── main.py          — точка входа
├── engine.py        — цикл приложения и обработка команд
├── core.py          — операции с таблицами и записями
├── parser.py        — разбор значений, присваиваний и условий
├── utils.py         — чтение, сохранение и удаление файлов данных
├── decorators.py    — обработка ошибок, подтверждение, таймер и кэш
└── constants.py     — общие настройки

docs/                — записи демонстраций
Makefile             — команды установки, запуска, проверки и сборки
pyproject.toml       — метаданные, зависимости и настройки инструментов
uv.lock              — зафиксированные версии зависимостей
```
