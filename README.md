# Primitive DB

Учебная консольная база данных на Python.

Программа поддерживает создание и удаление таблиц, просмотр их списка,
а также добавление, чтение, обновление и удаление записей.

Структура таблиц хранится в файле db_meta.json, а записи каждой таблицы —
в отдельном JSON-файле в директории data/. Результаты выборки выводятся
в консоль с помощью PrettyTable.

## Требования

- Python 3.12 или новее
- uv

## Установка для разработки

```bash
uv sync
```

## Запуск

```bash
uv run database
```

Альтернативный запуск:

```bash
uv run python -m primitive_db.main
```

## Управление таблицами

Доступные команды:

- `create_table <имя_таблицы> <столбец1:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `help` — показать справку.
- `exit` — завершить программу.

Поддерживаемые типы столбцов: `int`, `str`, `bool`.

Столбец `ID:int` добавляется автоматически. Указывать его при создании
таблицы не нужно.

Имена таблиц и столбцов должны удовлетворять правилу Python
`str.isidentifier()`: например, `users`, `user_name`, `age`.
Повторяющиеся имена столбцов не допускаются.

### Пример использования

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit
```

### Хранение метаданных

Имена таблиц и структура столбцов сохраняются в файле `db_meta.json`
в текущей рабочей директории, из которой запущена программа.

При повторном запуске из той же директории программа загружает
ранее сохранённые метаданные.


## CRUD-операции

Перед работой с записями создайте таблицу:

```text
create_table users name:str age:int is_active:bool
```

### Добавление записи

```text
insert into users values ("Sergei", 28, true)
```

Значения указываются в порядке столбцов при создании таблицы.
Все пользовательские поля обязательны.

Значение ID передавать не нужно: оно генерируется автоматически
как максимальный ID среди текущих записей плюс один.
Для пустой таблицы первый ID равен 1.

### Чтение записей

Все записи:

```text
select from users
```

Записи по условию:

```text
select from users where age = 28
```

Результат выводится в виде таблицы с помощью PrettyTable.

### Обновление записей

```text
update users set age = 29 where name = "Sergei"
```

Можно обновить несколько полей:

```text
update users set age = 30, is_active = false where name = "Sergei"
```

Обновляются все записи, соответствующие условию.
Изменять ID нельзя.

### Удаление записей

```text
delete from users where ID = 1
```

Удаляются все записи, соответствующие условию.

### Информация о таблице

```text
info users
```

Команда показывает имя таблицы, столбцы с типами и количество записей.

### Правила ввода

- Строки вводятся в двойных кавычках: `"Sergei"`, `"Иван Петров"`.
- Целые числа вводятся без кавычек: `28`, `-5`.
- Логические значения вводятся без кавычек: `true`, `false`.
- Тип значения должен соответствовать типу столбца.
- В `where` поддерживается одно условие равенства.
- Для `update` и `delete` условие `where` обязательно.
- Команда `select` без `where` возвращает все записи.

### Хранение записей

Записи таблицы `users` сохраняются в файле `data/users.json`.

После успешного добавления, обновления или удаления записей изменения
сохраняются в файл. При запуске из той же рабочей директории
ранее сохранённые данные доступны снова.

При создании таблицы создаётся пустой файл данных.
При удалении таблицы удаляются её метаданные и файл данных.

Файл `db_meta.json` и директория `data/` исключены из Git
через `.gitignore`.

uv build

После сборки выполните:

```bash
uv tool install --force dist/primitive_db-0.1.0-py3-none-any.whl
```

Запуск установленной программы:

```bash
database
```
