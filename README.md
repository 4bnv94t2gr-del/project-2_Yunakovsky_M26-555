# Primitive DB

Учебный проект на Python: разработка консольной базы данных.

## Требования

- Python 3.12 или новее
- uv

## Установка

```bash
uv sync
```

## Запуск

```bash
uv run project
```

Альтернативный запуск:

```bash
uv run python -m primitive_db.main
```

На текущем этапе программа выводит сообщение:

```text
DB project is running!
```
